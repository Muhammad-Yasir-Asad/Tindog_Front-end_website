# TinDog — Responsive Landing Page

A playful, responsive landing-page project built with **HTML, CSS, JavaScript, and Bootstrap**. The design practices modern landing-page structure, responsive layouts, and clear calls to action.

## ✨ Highlights
- Responsive layout using Bootstrap
- Hero section and promotional content
- Reusable layout and styling patterns
- Frontend interactions with JavaScript where implemented

## 🛠️ Tech Stack
HTML5 · CSS3 · JavaScript · Bootstrap

## 🚀 Run Locally
1. Clone this repository:
   `git clone https://github.com/Muhammad-Yasir-Asad/Tindog_Front-end_website.git`
2. Open the project directory.
3. Launch `index.html` in a browser.

## 🎯 Purpose
A frontend practice project for building responsive marketing pages and improving layout, styling, and component design skills.
